5. List of Figures
6. List of Tables
7. Chapter 1: Introduction
8. Chapter 2: Literature Review
9. Chapter 3: Methodology
10. Chapter 4: System Analysis and Design

14. Appendices, if used

## Figures

- Insert every figure close to the paragraph that first discusses it.
- Put the caption below the figure using the exact title from the List of
  Figures.
- Use landscape pages for the component diagram, class diagram, ERD, and
  long sequence diagrams.
- Use the anonymised screenshots in `docs/report/screenshots`.
- Do not include Figure 1.1 in the List of Figures unless a final Gantt chart
  is inserted.
- Avoid using the same screenshot twice unless Chapter 4 needs it as interface
  design evidence and Chapter 5 needs it as implementation evidence.

## Tables

- Put the table title above each table.
- Repeat the header row when a table continues to another page.
- Prevent a short table row from being divided across two pages where
  possible.
- Update all page numbers in the List of Tables after pagination is final.

## References

- Sort references alphabetically.
- Use APA hanging indentation.
- Use one consistent line spacing rule required by the faculty.
- Keep DOI and website URLs as working links.
- Confirm that WHO 2024 AI guidance is cited as `2024a`.
- Confirm that WHO Physical Activity is cited as `2024b`.

## Final Formatting

- Use Heading 1 for chapter titles.
- Use Heading 2 and Heading 3 for numbered sections and subsections.
- Generate the Google Docs table of contents only after applying headings.
- Use Roman numerals for front-matter pages if required by the faculty.
- Start Arabic page numbering from Chapter 1 if required.
- Check figure and table captions after inserting page breaks.
- Search the document for `[INSERT`, `Working References`, `Figure 1.1`,
  `TODO`, and empty page-number placeholders.

## Final Content Check

- Abstract remains below 300 words.
- The mock AI provider is clearly distinguished from the optional real
  provider.
- HTML report output is not described as PDF.
- The system is described as general-wellness decision support, not a
  clinical or medical system.
- Planned usability, performance, security, and real-AI evaluation are not
  described as completed.
- Screenshots do not reveal real personal email addresses or sensitive data.
